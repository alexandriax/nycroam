Other sources baked into these files:
  - MTA (subway stations, routes, structure types, GTFS stop sequences and bus
    routes) — https://www.mta.info/developers
  - NYC Open Data (borough boundary for the shoreline clip, 2020 Neighborhood
    Tabulation Areas) — https://opendata.cityofnewyork.us/
  - USGS / AWS Terrain Tiles, Terrarium format (elevation) —
    https://registry.opendata.aws/terrain-tiles/
  - Citi Bike GBFS station_information (dock locations and capacities) —
    https://gbfs.citibikenyc.com/gbfs/gbfs.json
  - OldNYC marker coordinates, used only to build deep links — see
    geo/OLDNYC_NOTICE.txt
